This mod is intended for players who use keep inventory and the mentally disturbed (same group am I right hur hur hur).  
On respawn there is a small chance that your inventory's contents will be wiped, even with keep inventory on.  
This chance can be moddified in the common config.  
This mod was specially for the mod pack The Book of John, which you can find at https://github.com/SourpussMaggie/Book-Of-John
